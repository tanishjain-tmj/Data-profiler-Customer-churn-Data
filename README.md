🛒 Customer Churn Data Preprocessing & EDA

📌 Overview

This project analyzes e-commerce customer behavior and prepares the data for customer churn prediction.

🎯 Objectives

Collect data from CSV, JSON, SQL, and API sources

Clean and preprocess customer data

Handle missing values, duplicates, and outliers

Perform Univariate, Bivariate, and Multivariate EDA

Generate a data profiling report

Prepare an ML-ready dataset

📊 Main Dataset

E-commerce Customer Data (CSV)

The CSV is used as the primary customer dataset. Small JSON and SQL datasets provide supplementary customer information.

Target Variable

churn

0 → Customer does not churn

1 → Customer churns
